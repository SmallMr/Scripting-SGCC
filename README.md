# SGCC Usage 网上国网用电

网上国网小组件：本月日历、昨日 / 本月 / 上月 / 本年用电与电费、最近 14 天趋势，以及年度阶梯进度。

## 使用

直接导入仓库根目录的 `Scripting-SGCC.scripting`，或在 Scripting 中新建脚本后放入本仓库文件。

1. 打开脚本设置，填写网上国网**手机号**和**密码**（密码只存在本机钥匙串）。
2. 首次登录（新设备）国网会要求短信验证：点「发送短信验证码」，把收到的 6 位验证码填入「短信验证码」，再点「立即刷新」或预览小组件。
3. 添加小组件。支持小号、中号、大号，以及锁屏的矩形、圆形、行内样式。

### 桌面组件

- **大号**：本月累计、昨日用电、本月每日用电日历（最高 / 最低 / 今天分色）、上月与本年汇总、当前阶梯。
- **中号**：昨日、本月、上月、本年四项汇总，最近 14 天日用电量，以及当前阶梯。
- **小号**：昨日、本月、上月、本年四项内容与当前阶梯；可在三项、四项列表、四项模块之间切换。

### 多户号

长按小组件 → 编辑小组件 → 参数，填从 0 开始的整数：`0` 为第一户（默认），`1` 为第二户，以此类推。最多读取 6 个户号。

### 设置项

- **网上国网账号**：手机号、密码、短信验证码
- **数据**：立即刷新、清除数据缓存
- **阶梯**：第一阶梯上限（默认 2760 度）、第二阶梯上限（默认 4800 度），按年累计
- **小号组件**：三项 / 四项列表 / 四项模块
- **数据更新**：4 / 6 / 8 / 12 / 24 小时

> 小号组件的三种模式保存在偏好设置中，修改后会自动刷新桌面组件。

## 数据与刷新

- 直连网上国网 App 接口，缓存时长由设置里的「数据更新」决定（默认 4 小时）；请求失败时回退到缓存。
- 「清除数据缓存」后下次刷新会重新请求。
